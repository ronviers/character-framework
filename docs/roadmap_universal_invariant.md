# Roadmap — is there a universal protected invariant? (the classification question)

> **STATUS (2026-06-21) — Phase A resolved: clean negative on the import.** The §5 prompt returned (three
> passes; `universal_invariant returns.md`) — **no** model-independent classifying structure; the per-substrate
> invariant is real and named (Polettini gauge-cohomology + Harary balance). Folded to receipts §Universal-
> invariant classification + frontier `universal-invariant-classification`. The deformation framing (Phase B)
> is **obstructed** and dropped; the bet relocated to a **composition law** — see
> [`build_composition_law.md`](build_composition_law.md) (the re-aimed Phase C). Retained below for the §5
> prompt archive and the phase structure.

The make-or-break the program has been circling without striking. Two independent belief-mode reads
of the framework (a weak model and a strong one, run separately) converged on the same hinge: either
there is a **universal protected invariant** under all the instances — making *character* a genuine
physical category, a new state variable — or there is not, and *character* is a powerful organizing
metaphor grouping several distinct phenomena under one name. Everything else rests on that boundary.

**Why we've been stuck.** Effort has gone to two things: banking real *instances* of minting (DNA
network, gyrators, repressilator) and running the *transverse-decomposition test* (TDT) on metric
observables. Both are consistent with character being real; neither *tests* whether the invariant is
universal. More gyrators do not settle whether `sign(𝒜)` is one invariant or three coincidences
wearing one name. The crux is a **classification** question, and we have no classification work-item.
This roadmap opens one.

---

## 0. The crux, stated sharply

> Across maximally different substrates that each carry a protected nonequilibrium circulation, is the
> cycle-affinity sign `sign(𝒜)` *one invariant of a single classifying structure* — so that "the same
> character" in two substrates is related by a structure-preserving map, and "different characters"
> require a singular event to connect — or is it a substrate-by-substrate quantity that merely shares a
> name?

Two verdicts, both clean, both bankable:

- **↑ (physical category).** A model-independent classifying structure exists; `sign(𝒜)` is its
  universal invariant; the equivalence classes are substrate-independent and check against the banked
  instances. Then *character* is real in the strong sense — a third independent description a driven
  system requires (state · metric response · owned circulation), none reconstructible from the others.
- **✗ (organizing metaphor).** No structure-preserving map carries one substrate's protected bit to
  another; the classes are substrate-specific. Then *character* is a lens — a family of analogies, not
  a category. This is the deepest invalidation available, and exactly the one to prefer over a soft pass.

---

## 1. The candidate invariant (what is actually being tested)

The framework's candidate is precise, which is what makes the question answerable:

- **The object:** `sign(𝒜)`, the sign of the Schnakenberg cycle affinity of the drift split
  `b = −a∇V + 𝒜·l`, `⟨l,∇V⟩ = 0` (gradient + transverse circulation).
- **Gauge-irremovable:** invariant under state relabeling and smooth rate-retuning; flips only when the
  cycle is *rewired* (an edge added / cut / reversed) or driven through the singular set `𝒜 = 0`.
- **Welded to signed-graph balance** (the `binding` receipt): a frustrated cycle ⟺ nonzero affinity
  (Harary unbalance ⟺ Kolmogorov irreversibility). So the candidate is well-defined, not hand-waved.
- **Sub-integer, not integer** (`chirality-protection`): it is a *sign*, gauge-irremovable but with
  sub-integer holonomy — **not** a Chern-type integer winding. A classification that presupposes an
  integer invariant is the wrong import.
- **Superselected** (`pa:transverse-decomposition`): barred from the leading large-deviation
  observables, reaching them only at the prefactor — "metric modulates topology, cannot create or
  destroy it." This is the premise the whole classification edifice stands on (see §3, the colloid).

The classification question is: *does this one object organize into substrate-independent equivalence
classes?*

## 2. The navigation (phases + pre-registered decision rules)

Run A and the colloid (§3) in parallel; B follows A's framing; C follows B.

### Phase A — pose the import question (the outbound prompt; cheap, parallel)

Send the prompt in §5 to the research channel. Same shape as the curvature prompt that just closed
cleanly: a self-contained, jargon-free question, **forced import or clean negative.**

- **A names a forced, substrate-independent classifying structure** → proceed to C; flag the import for
  `character_prior_art.md`.
- **A returns a clean negative** (no model-independent classification; substrate-specific) → the
  metaphor-verdict candidate; corroborate with B before retiring.
- **A returns "case-by-case / partial"** → it narrows *which* mathematics; feeds B and C.

### Phase B — the operational test (cross-substrate transfer; runnable, synthetic = calibration)

The runnable backbone a classification theorem needs, and the operational form of "is it one
invariant." Take two **maximally different** banked instances (e.g. the fuel-driven DNA network and a
Brownian gyrator) and test whether `sign(𝒜)` is genuinely the *same object* across them:

1. Construct an explicit structure-preserving map between the two protected loops (the candidate
   morphism: relabeling + smooth deformation, no edge rewiring).
2. Transport `sign(𝒜)` along it. Does it carry faithfully — same sign, preserved — and flip **only**
   when the path is forced through the achiral `𝒜 = 0` set?
3. Control: a map that crosses `𝒜 = 0` (rewiring) *must* change the class; a map within a class *must
   not*.

- **✓** the invariant transports under the structure-preserving map, flips only across `𝒜 = 0` →
  operational evidence for one invariant; strengthens C. *(Half the machinery exists:
  `battery:scale-covariant-circulation` already transports the bit across **scales**; the retired
  `cross-stratum-transduction` moved it **laterally**. The gap is transport across **distinct
  substrates** — which is exactly the question.)*
- **✗** no structure-preserving map exists, or the "invariant" means different things in the two →
  operational evidence for the family-verdict (the clean negative).

### Phase C — build the classification (only if A/B point somewhere)

Instance the named structure: define the **classes**, the **morphisms** (what deformations preserve a
class), and the **singular events** (what changes it — rewiring, crossing achirality). Then show the
**same class structure on ≥3 banked instances** (DNA, gyrator, repressilator/triad), forced-not-fitted.

- **↑** a universal invariant + a substrate-independent classification that checks across the instances
  → **crosses the line**: character is a physical category. Core edit at the safe altitude; receipt as
  the proof shard; the import logged.
- **✗** the classification holds only *within* substrate classes → family-verdict; retire to the
  metaphor reading. Record the negative.

### Phase D — promote or retire

Per C's verdict. Either way the crux is no longer circled — it is struck.

## 4. Tripwires (what makes a return — or a build — unusable)

- **Forced, not fitted.** A classification reverse-engineered to fit our instances is the exact failure
  it must guard against. The structure comes from a named result first, *then* is checked against the
  instances.
- **Substrate-independence is the whole point.** A classification that works only within one substrate
  class does not answer the question — it confirms the metaphor.
- **Sub-integer, not integer.** Do not import Chern / winding-number machinery that presupposes an
  integer invariant unless the integer is justified; the bit is a gauge-irremovable *sign*.
- **Modulation, not generation.** The metric sector biases but cannot create or destroy the bit. Any
  claim that local structure *generates* the protected class is wrong (it would undo the transverse
  theorem).
- **State the manifold.** Parameter-space vs state-space — say which carries the classification; do not
  bridge them silently (the logged curvature caveat).
- **Seams ≠ bits.** Classifying the transitions (already done) is not classifying the characters (the
  open thing). Keep them distinct.

## 5. The outbound prompt (Phase A — send this)

---

### Identification/derivation prompt — is the cycle-affinity sign a *universal invariant* with a classification theory?

Self-contained nonequilibrium-statistical-mechanics / topology / category-theory question for the
outbound research channel. **No domain jargon by design** — any strong stochastic-thermodynamics,
algebraic-topology, singularity-theory, or category-theory model should engage cold. **The goal is
identification, then a forced classification** (or a clean negative). We have a candidate invariant of
driven systems and one question: is it *universally* the invariant of a single classifying structure,
with genuine equivalence classes, or merely a substrate-by-substrate quantity sharing a name? We want
the **named established structure + the explicit classifying object** so we can import it — or a clear
"there is none; it is substrate-specific," which is equally usable.

#### 0. The setup (plain)

A driven, dissipative stochastic system sits in a nonequilibrium steady state. Its drift splits into a
relaxational (gradient) part and a circulating (transverse) part,

```
b(x) = −a(x) ∇V(x)  +  𝒜 · l(x) ,     ⟨l, ∇V⟩ = 0 ,
```

and `𝒜 ≥ 0` measures the steady circulation (the cycle affinity; `𝒜 = 0` is equilibrium / detailed
balance). The object of interest is **`sign(𝒜)`** — the *sense* of the circulation. Three established
facts about it (the part we already have):

- **Gauge-irremovable.** `sign(𝒜)` is invariant under relabeling the states and under any smooth
  retuning of the rates or the drive strength. It flips only when the cycle is **rewired** (a
  transition added, cut, or reversed) or driven through `𝒜 = 0`.
- **A signed-graph invariant.** A nonzero affinity is exactly a *frustrated* (Harary-unbalanced) signed
  cycle; `sign(𝒜)` is the gauge-irremovable sign of that unbalance (Kolmogorov irreversibility).
- **Sub-integer, and superselected.** It is a sign, not an integer winding number (its holonomy is
  sub-integer). And it is *barred from the leading large-deviation observables* of the relaxational
  sector (the quasipotential / escape barrier is invariant under `𝒜`; transverse-decomposition,
  Graham–Haken, Freidlin–Wentzell): the metric sector can **modulate** it but cannot **create or
  destroy** it — a superselection rule.

The same structure is read off systems that share nothing else: chemical reaction networks, Brownian
gyrators, driven colloids on a ring, quantum error-correcting codes, aging glasses.

#### 1. The question

**Is `sign(𝒜)` — the gauge-irremovable cycle-affinity sign — universally (model-independently) the
invariant of a single classifying structure, with substrate-independent equivalence classes of
protected circulations, or merely the leading analytic/topological label of each substrate taken
separately?**

By "classifying structure" we mean: a setting in which protected circulations fall into equivalence
classes such that (i) two circulations are in the same class iff connected by a structure-preserving
deformation that does **not** cross the singular set `𝒜 = 0`; (ii) crossing `𝒜 = 0`, or rewiring,
moves between classes; (iii) the classes are the *same objects* across substrates. Candidate homes:

- **signed-graph / gauge cohomology** (the balance class of a signed graph; `sign(𝒜)` as an element of
  `H¹(·, ℤ₂)` or the graph's balance group);
- **homotopy** — `π₀` of the space of admissible drift fields with the `𝒜 = 0` locus removed (classes
  = path-components);
- **cobordism / a fusion (monoidal) algebra** — circulations that can be born, **merge** (coalescence),
  and **split** (minting), giving a creation/annihilation or fusion structure on the classes;
- **singularity / catastrophe theory** — the classes as strata, the `𝒜 = 0` events as their bounding
  singularities (Thom/Arnold/Golubitsky–Schaeffer);
- **a category of characters** — objects = protected circulations, morphisms = structure-preserving
  maps, a (symmetric monoidal) composition = coupling/minting;
- **a large-deviation universality class** — substrates sharing one rate function / quasipotential,
  indexed by `sign(𝒜)` (the metric sector identical, the topological sector the label).

#### 2. Tasks (be specific; cite)

1. **Name the structure, or state there is none.** Is there an established, model-independent
   classification of protected nonequilibrium circulations under which `sign(𝒜)` is the universal
   invariant? If yes: the theorem, its hypotheses, the **explicit classifying object** (which
   group/space/category, what the classes are), and the canonical reference. If no single result, say
   which candidate above applies under what conditions, and where universality fails.
2. **The invariant's range.** Is the protected bit `ℤ₂` (a sign), `ℤ` (an integer winding), or richer?
   We have evidence it is gauge-irremovable but **sub-integer** — so an integer-invariant classification
   (Chern/winding) is the wrong import unless justified. Confirm or correct.
3. **The morphisms (deformation / transport).** Characterize the structure-preserving maps that
   **preserve** a class and the singular events that **change** it. Do coarse-graining (scale) and
   cross-substrate maps preserve `sign(𝒜)`? State what a "structure-preserving map" between two
   different substrates' circulations *is*.
4. **Composition.** Minting (coupling creates a protected bit **neither part carried**) and coalescence
   (merging). Is there an algebra / monoidal / fusion structure on the classes (creation–annihilation,
   or a tensor of characters)? Named precedent?
5. **Which manifold.** Does the classification live on the **state space** (the circulation geometry at
   a fixed operating point) or the **parameter / control space** (as couplings are swept)? Distinguish
   sharply; do not conflate.
6. **The single importable statement — or the negative.** Distil to one citable proposition: either
   *"protected nonequilibrium circulations are classified by [named structure], with `sign(𝒜)` the
   universal invariant [Author, Year, Thm N]"* (with hypotheses + a cross-substrate check), **or**
   *"there is no model-independent classification; the cycle-affinity sign is a substrate-specific
   quantity (a family of analogies, not one invariant)."* A clean negative is a fully acceptable,
   expected outcome — say so plainly if that is the truth.

#### 3. Constraints / what makes a report unusable

- **Forced, not fitted.** A classification reverse-engineered to reproduce a chosen set of examples is
  the failure we are guarding against. The structure must come from a named result and *then* be checked
  against the substrates.
- **Substrate-independence is the bar.** A scheme that classifies only within one substrate family
  (only reaction networks, only codes) does not answer the question — it confirms the negative.
- **Sub-integer, not integer.** Do not assume an integer topological invariant; the object is a
  gauge-irremovable sign. If you claim an integer, justify it.
- **Modulation, not generation.** The metric sector cannot create or destroy the bit (superselection).
  Any construction in which local/metric structure *generates* the protected class is wrong.
- **State the manifold.** Leaving state-space vs parameter-space ambiguous, or bridging them silently,
  makes the report unusable (Task 5 is load-bearing).
- **Be honest about a negative.** If `sign(𝒜)` is generically substrate-specific with no universal
  classifying structure, say so — that retires the framework's central bet cleanly, which is a result,
  not a disappointment.
